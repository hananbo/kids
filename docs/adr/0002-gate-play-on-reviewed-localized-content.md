# Gate play on reviewed content in the player’s language

AI generation and web imports enter editorial review with source references. An authorized parent or platform admin must approve an item before it can be played, and edits leave the last published version available while review continues. Language-dependent fields must be ready in the player's chosen language, while numeric values and media explicitly marked as shared can fall back to the base item, so games can reuse assets without mixing languages.

Approval covers the exact content and language served to players, including any translations or assets generated during publishing. Changing a shared field requires reapproval for every language that inherits it. Reviewers see source links in Filament and players receive approved media from platform-managed storage.

Runs keep the published versions they start with. Explicitly withdrawing a version ends any active run using it and preserves progress from completed runs.
