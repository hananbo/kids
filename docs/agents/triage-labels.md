# Triage labels

Use the corresponding value in the ticket's `Status:` field.

| Role | Status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer review is pending |
| `needs-info` | `needs-info` | More information is needed |
| `ready-for-agent` | `ready-for-agent` | Ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Maintainer declined the issue |
